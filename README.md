# SkillSwap - Professional Networking & Skill-Sharing Platform

A modern web application built for the hackathon that enables professionals and learners to connect, showcase their tech skillsets, and share knowledge seamlessly.

## 🚀 Project Features
- **Dynamic Skill Registry:** Users can dynamically manage, list, and showcase their technical proficiencies on their profile.
- **Professional Social Feed:** Real-time posting layout for users to share updates and network updates.
- **Interactive Networking:** A structured connection system for mutual request handling and building professional networks.

## 🛠️ Built With
- **Frontend Core:** React, TypeScript, Vite
- **Styling & Layout:** Tailwind CSS, Shadcn UI
- **Backend Architecture:** Supabase (PostgreSQL Database & Authentication)
